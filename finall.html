AutomatedAnalytics: upload a sales file, get clean data, live KPIs and written insights

A full-stack platform I built from scratch. A Pandas pipeline cleans any sales file and maps its columns to a standard layout. A local language model helps when a column name is unfamiliar. Everything lands in MySQL, and a Flask app shows the KPIs, charts and plain-language insights.

  1. UploadAny sales CSV or Excel file
  2. Clean and mappipeline.py fixes types, fills gaps and maps columns
  3. StoreRows saved to a MySQL database
  4. ReportFlask dashboard with KPI cards, charts and top products
  5. ExplainInsights written by a local Ollama model (llama3.2:3b)

Built with Python, Flask, Pandas, MySQL, Ollama, HTML/CSS/JS. A four-page Power BI report (executive, sales, customer, profit) accompanies it.
